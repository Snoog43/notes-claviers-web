Agrégateur de tests

Notes de switchs et de claviers

Les notes de plusieurs testeurs, réunies produit par produit. Chaque note reste celle de son auteur, avec un lien vers son test.

      Note combinée : chaque testeur a sa propre échelle (ThereminGoat note rarement au-dessus de 85/100, Aurore utilise les étoiles…). Pour comparer, chaque note est convertie en rang centile dans sa source (100 = meilleur produit de ce testeur, 50 = au milieu), puis on fait la moyenne. C'est un repère, pas une vérité.

      Toutes les notes, sous-notes et points forts/faibles appartiennent à leurs auteurs ; suivez les liens pour lire leurs tests complets.
